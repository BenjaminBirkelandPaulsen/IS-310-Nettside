# IS-310-Nettside

En enkel nettside laget som skjelett for publisering med GitHub Pages.

## Filer

- `index.html` – hovedsiden
- `styles.css` – enkel styling

## Publisering i GitHub Pages

1. Gå til repositoryet på GitHub.
2. Velg **Settings → Pages**.
3. Under **Build and deployment**, velg branch (for eksempel `main`) og `/ (root)`.
4. Lagre – siden blir publisert automatisk.
