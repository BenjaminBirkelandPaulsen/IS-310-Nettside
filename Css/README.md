# CSS-struktur

`index.html` laster `index.css`, som importerer disse fem filene:

| Fil | Innhold |
| --- | --- |
| [default.css](default.css) | Grunnstil, forside, navigasjon, footer, felles kort og animasjoner |
| [om-oss.css](om-oss.css) | Om oss |
| [ambisjoner.css](ambisjoner.css) | Våre ambisjoner |
| [medlemmer.css](medlemmer.css) | Medlemskarusell, profilbilder, sosiale lenker og medlemspresentasjoner |
| [video.css](video.css) | Gruppevideo |

Mobilregler for om oss, ambisjoner og medlemmer ligger i seksjonens egen fil. Felles mobilregler ligger i `default.css`.

Profilbildene i den horisontale medlemspresentasjonen finnes under `.horizontal-image` i `medlemmer.css`.
